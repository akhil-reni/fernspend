Fernspend API

The Fernspend REST API lets you read and submit expenses, manage your workspace and react to events in real time. All endpoints live under /api/v1 and speak JSON.

Authentication

Browser sessions use the fs_session cookie. For scripts, send the same session token as a bearer token:

curl https://app.fernspend.io/api/v1/me \
  -H "Authorization: Bearer $FERNSPEND_TOKEN"

Session tokens are JWTs signed by Fernspend and expire after 8 hours. Personal access tokens are coming soon.

Expenses

GET/api/v1/expenses

Lists expenses in the current workspace, 25 per page.

q        free-text search on merchant, category and note
status   pending | approved | rejected | reimbursed
sort     <field>:<asc|desc>  — spent_at, merchant, category, amount_cents, status, created_at
page     1-based page number

POST/api/v1/expenses

{ "merchant": "Delta Air Lines", "amount": 482.30, "category": "Travel", "spent_at": "2026-11-02", "note": "SFO → JFK" }

PATCH/api/v1/expenses/:id

Admins and owners can set status to approved, rejected or reimbursed.

Webhooks Enterprise

Register an HTTPS endpoint and Fernspend will POST events such as expense.created, expense.approved and expense.reimbursed.

POST   /api/v1/webhooks             { "url": "https://example.com/hooks" }
POST   /api/v1/webhooks/:id/test
GET    /api/v1/webhooks/:id/deliveries
DELETE /api/v1/webhooks/:id

Verifying signatures

Every delivery carries a Fernspend-Signature header: a compact JWS (RS256) whose payload contains body_sha256, the hex SHA-256 of the raw request body. Fetch our public keys from the JWKS endpoint and select the key by kid.

GET /.well-known/jwks.json
GET /api/v1/integrations/signing-key.pem     # same key, PEM-encoded
import { createPublicKey, createHash } from "node:crypto";
import jwt from "jsonwebtoken";

const pem = await (await fetch("https://app.fernspend.io/api/v1/integrations/signing-key.pem")).text();

export function verify(rawBody, signature) {
  const claims = jwt.verify(signature, createPublicKey(pem), { algorithms: ["RS256"] });
  const digest = createHash("sha256").update(rawBody).digest("hex");
  if (claims.body_sha256 !== digest) throw new Error("body mismatch");
  return JSON.parse(rawBody);
}
